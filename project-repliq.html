Repliq

Turns a screen recording into an executable workflow, run by a ReAct agent behind a zero-trust credential vault.

About

A production-grade autonomous agent system that converts screen recordings into executable workflows, driven by a ReAct (Reason–Act–Observe) planning loop, LLM reasoning, and iterative tool execution.

You demonstrate a task once. The agent watches, reasons about what you did, and can then repeat it — calling real tools, handling its own failures, and never holding a secret it could leak.

Key features

  • A ReAct planning loop — reason, act, observe — that turns a demonstrated task into a repeatable multi-step workflow.
  • An MCP-compatible tool-calling layer with full execution tracing, retry and error handling, and async orchestration through FastAPI.
  • A zero-trust security architecture with Fernet-encrypted credential vaulting and OAuth 2.0, so sandboxed agents never access long-lived secrets during autonomous execution.
