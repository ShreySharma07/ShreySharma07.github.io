KARMA

Five LLM agents that write, test, and tune GPU kernels — reaching 8.99× over the PyTorch eager baseline on a 6 GB consumer card.

About

A five-agent orchestration pipeline — classifier → planner → coder → verifier → reflector — that autonomously writes, tests, and iteratively refines GPU code under hardware-grounded prompting.

The interesting problem was not generating kernels. It was trusting them: an LLM optimising against its own benchmark will happily learn to cheat the benchmark. Most of the system is the part that makes that impossible.

Key features

  • Reaches 8.99× over the PyTorch eager baseline and 1.08× over torch.compile on a consumer 6 GB GPU — results prior work required H100 clusters to reach.
  • A closed-loop verification harness — compile → 3-seed correctness check → determinism gate → interleaved benchmarking — that structurally blocks LLM reward hacking, yielding 0% false-positive correctness across all reported results.
  • A RAG semantic memory layer on ChromaDB for cross-task knowledge transfer. One authored knowledge entry lifted agent performance from 0.26× to 1.09× on an identical task — measurable in-context learning across runs.
  • Ablation studies on KernelBench — knowledge base, pre-flight profiling, reflection agent — toward a workshop paper submission.
