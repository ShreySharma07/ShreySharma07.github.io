Current paper work

KARMA: Multi-Agent LLM System for Automated GPU Kernel Optimization

In preparation

Workshop paper · ablation studies on KernelBench

Five LLM agents write, verify, and iterate on GPU kernels. A closed verification loop structurally blocks reward hacking, so every reported speedup is real. The paper isolates what drives the results: the knowledge base, pre-flight profiling, and the reflection agent, one variable at a time.

classifier→planner→coder→verifier→reflector

Each kernel passes compile → three-seed correctness → determinism gate → interleaved benchmarking before it counts. A ChromaDB memory carries technique between tasks: one authored entry moved the agent from 0.26× to 1.09× on an identical task.
