01

Repliq

An autonomous agent platform that turns a screen recording into an executable workflow, driven by a ReAct reason–act–observe loop over LLM planning and iterative tool execution. Credentials sit behind a zero-trust vault — Fernet encryption fronted by OAuth 2.0 — so sandboxed agents never hold a long-lived secret. The MCP-compatible tool layer carries full execution tracing, retry and error handling, and async orchestration through FastAPI.

02

KARMA

A five-agent LLM pipeline — classifier → planner → coder → verifier → reflector — that writes and tunes CUDA kernels under hardware-grounded prompting. It reaches 8.99× over PyTorch eager and 1.08× over torch.compile on GPT's GELU kernel, at 87.9% of theoretical peak memory bandwidth — on a 6 GB consumer GPU, where prior work needed H100 clusters. A deterministic closed-loop harness (compile → 3-seed correctness → determinism gate → interleaved benchmarking) structurally prevents reward-hacking, holding 0% false-positive correctness across every reported result. A RAG playbook over ChromaDB moves technique knowledge between kernels: one authored entry lifted agent strategy from 0.26× to 1.09× on an identical task, and composing techniques took matmul from 0.585× to 0.975× of vendor-tuned cuBLAS.

CUDA · Python · Multi-agent LLM · ChromaDB · RAG

Math-Specialized Llama 2
